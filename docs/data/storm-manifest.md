# Paper case-study manifest

The fixed Humberto, Kiko, and Otis case studies are represented by the
scientific catalog and the retained result files in `release/`. They are
separate from the model-training cohorts and from the companion website's
rolling explorer archive.

Use [`docs/reproduction.md`](../reproduction.md) for the pinned evaluation
commands and [`docs/data/huggingface.md`](huggingface.md) for downloading the
case-study assets. Website CSV/JSON overlays and browser tables are generated
in the companion `geo2wf` application repository checkout.
