# Website and explorer

The StormSense website, explorer assets, dashboard exports, and deployment
workflow are maintained in the companion `geo2wf` application repository checkout. This
scientific repository contains the model, data, and evaluation code consumed by
that application.

For the fixed scientific case studies, use the results and provenance in
[`results.md`](results.md), [`data/index.md`](data/index.md), and
[`reproduction.md`](reproduction.md). The application repository owns browser
routes, local explorer data, and R2 publication commands.
